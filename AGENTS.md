# Wskazówki dla agenta

To samodzielna, konfigurowalna wyszukiwarka ofert pracy. Informacje o uruchomieniu są w README.md; konfiguracja użytkownika w config.toml. Nie kopiuj profili, historii ofert, danych osobowych ani sekretów z innych projektów. Nie zapisuj stawek ani treści ofert w stanie. Sekrety pobieraj wyłącznie ze zmiennych środowiskowych lub GitHub Secrets i nie wypisuj ich w logach.

Kod i testy mają działać bez sieci na sztucznych danych. Bez wyraźnego zlecenia nie wysyłaj wiadomości, nie zmieniaj GitHub Secrets i nie publikuj projektu. Dane testowe muszą być fikcyjne.
